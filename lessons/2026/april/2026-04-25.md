# April 25 - Arrangement and Song Sections

## Focus
Move from interesting loops to a piece with sections, transitions, and returns.

## Modules
Erica Drum Sequencer, Acid Rain Constellation, Mutable Grids, Intellijel Metropolix, Pam's Pro Workout, Robaux DCSN-3

## Manuals To Skim
Erica Drum Sequencer, Constellation, Grids, Metropolix, Pam's Pro Workout, DCSN-3

## 60-Minute Plan
1. `0:00-0:10` Define four sections on paper: intro, groove, breakdown, final return.
2. `0:10-0:25` Build one pattern or state for each section.
3. `0:25-0:40` Use mutes, pattern changes, fills, or routing changes for transitions.
4. `0:40-0:55` Perform the four sections in order at least twice.
5. `0:55-1:00` Write down which transition felt weak and what module should handle it next time.

## Questions
- Does each section have a distinct role?
- What changes most effectively announce a transition: rhythm, harmony, or space?
- Which module is best for macro-structure in your rack?
- Did the breakdown reduce energy in a meaningful way or just mute things?
- Can the final return beat the first groove section?
