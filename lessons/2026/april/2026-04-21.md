# April 21 - Space, Delay, and Stereo Threat

## Focus
Build depth and width that feel ominous instead of lush-for-its-own-sake.

## Modules
Qu-Bit Nautilus, Erica Synths Black Delay, WMD SSF DPLR, Tiptop ZVERB, Make Noise Mimeophon, Qu-Bit Synapse, Qu-Bit Cascade, Kaona Stereo Weaver, Omnitone 7Path

## Manuals To Skim
Nautilus, Black Delay, DPLR, ZVERB, Synapse, Cascade, Stereo Weaver, 7Path

## 60-Minute Plan
1. `0:00-0:10` Patch one mono pad and one mono percussion layer.
2. `0:10-0:25` Create one deep delay network for the pad.
3. `0:25-0:40` Add a smaller, more rhythmic space around one percussion layer.
4. `0:40-0:55` Use stereo tools or feedback routing to widen the image without washing out the center.
5. `0:55-1:00` Listen in mono if possible and note what still works.

## Questions
- Which effect adds menace rather than comfort?
- Where should the center of the mix stay dry?
- What kind of repeats help complex drums instead of blurring them?
- Does stereo width come from timing, filtering, or level difference?
- Which ambient processor feels most "architectural" in your system?
